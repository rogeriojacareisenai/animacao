CONTROLES DE OBSTÁCULOS ATIVO

• Botão Direito no Chão: Adicionar objeto.
• Botão Esquerdo no Objeto: Selecionar.
• Segurar CTRL + Mouse: Mover posição (X, Z).
• Segurar ALT + Arrastar Cima/Baixo: Mudar Altura (Y).
• Segurar ALT + Arrastar Esq/Direita: Redimensionar Largura/Profundidade.
• Tecla DELETE / BACKSPACE: Remover objeto.
